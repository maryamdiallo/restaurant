# A Taste of Teranga

## Project Description
A Taste of Teranga is a simple restaurant website created using PHP, HTML, and CSS. The website features traditional Senegalese dishes, menu prices, and restaurant contact information.

This project was created for my PHP class assignment to practice using separate header and footer files.

## Technologies Used
- PHP
- HTML
- CSS
- MAMP

## Project Files
- **header.php** – Contains the website title and navigation menu.
- **index.php** – Displays the restaurant menu and contact information.
- **footer.php** – Contains the copyright information.
- **style.css** – Styles the website.

## Features
- Restaurant homepage
- Senegalese food menu with prices
- Contact information
- Navigation links
- Reusable header and footer using PHP `include`

## How to Run
1. Download the project files.
2. Place the restaurant folder inside the MAMP `htdocs` directory.
3. Open MAMP and start the Apache server.
4. Set the MAMP document root to the restaurant folder.
5. Open `http://localhost:8888/index.php` in your browser.

## Purpose
The purpose of this project is to learn how to organize PHP websites using separate header and footer files.
